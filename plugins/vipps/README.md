# Vipps MobilePay plugin (renamed)

This plugin is now [`vipps-developer`](../vipps-developer). The name changed so it is not confused with the
third-party Vipps plugins that people also install.

Install the new one:

```bash
claude plugin marketplace add vippsas/agent-toolkit
claude plugin install vipps-developer@agent-toolkit
```

This directory stays published on purpose. It holds a single skill that tells a coding agent the plugin has moved,
so anyone still on the old name finds out from their agent rather than from silence.
