# Changelog

Notable changes to the `vipps` plugin.

This plugin was renamed to `vipps-developer` in September 2026. It is kept installable so that an agent running on
the old installation says so instead of answering from stale skills, and it carries no integration guidance of its
own.

Everything up to and including 1.12.0 is the history of this plugin under its old name. Those entries, and every
release from here on, are in the [`vipps-developer` changelog](../vipps-developer/CHANGELOG.md).

## 1.14.0 - 2026-09-10

- New plugin logo showing both the Vipps and the MobilePay brand mark instead of the Vipps smile alone.

## 1.13.0 - 2026-09-09

- Made the plugin more vocal about itself being deprecated and that users should look for the new plugin.

## 1.12.0 - 2026-09-08

- Deprecated. Replaced the integration skills with a single `renamed` skill that tells an agent to install
  `vipps-developer` instead.
- For releases up to this point, see the [`vipps-developer` changelog](../vipps-developer/CHANGELOG.md).
